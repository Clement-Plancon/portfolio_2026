W—04 · Case study

Datametre

Un observatoire éditorial des données publiques françaises. Chaque chiffre devient une courte lecture — source, méthode, nuance. L'inverse d'un tableau de bord jetable.

Rôle
Design · Dev · Éditorial
Contexte
Open data · INSEE · data.gouv
Période
2024 → présent
Stack
JavaScript · D3 · Netlify
01
Overview

La France publie une quantité remarquable de données en open data. L'INSEE, data.gouv.fr, les ministères, l'OpenStreetMap France : tout est là, souvent de qualité, souvent peu lisible.

Datametre est le projet inverse d'un dashboard : on part d'un chiffre, on l'habite éditorialement, on le replace dans son contexte. Chaque figure est une courte lecture — ce qu'elle dit, ce qu'elle ne dit pas, comment elle a été construite.

En ligne : datametre.netlify.app ↗

02
Intention

Les dataviz les plus courantes font deux erreurs opposées : trop de chiffres sans récit, ou trop de récit sans source. Datametre tente une troisième voie — une viz éditorialisée, sobre, sourcée, courte.

L'audience visée : lecteur curieux, journaliste, étudiant, agent public qui prépare une note. Pas un public de spécialistes de la statistique.

03
Approche
  • Un chiffre, une page — Pas de dashboard, pas de filtres interactifs envahissants. Une figure, une lecture, une source.
  • Design éditorial — Rythme typographique soigné, respiration, hiérarchie claire. L'inspiration vient des pages économiques de la presse, pas des produits SaaS.
  • Vanilla JavaScript + D3 — Pas de framework. Les pages sont rapides, le code est lisible, l'ensemble vit tranquillement sur Netlify.
04
Décisions & compromis

Pas de CMS

Chaque figure est un fichier Markdown ou un petit module JS. L'édition passe par Git. C'est volontaire : la lenteur de la publication force à soigner ce qu'on publie.

Pas d'automatisation complète

On aurait pu scraper les sources et republier à chaque mise à jour. On s'est arrêté à mi-chemin : les scripts préparent la donnée, mais la publication reste manuelle, parce qu'elle demande une re-lecture éditoriale.

Formats natifs

SVG pour les figures, HTML pour les pages, pas d'images rastérisées. Datametre est à peu près aussi léger qu'il peut l'être.

05
Statut & suite

En publication irrégulière. Le projet est volontairement artisanal — j'y travaille entre deux projets, et je n'ai pas l'ambition d'en faire un média.

La suite immédiate : un petit système de collections, pour regrouper les figures d'un même thème (démographie, emploi, mobilité) sans tomber dans l'arborescence de site classique.
